A [make.fun](https://make.fun/bounty/u-clever-harbor-75-fortune-cookie-for-the-liquidated-38fd239c) bounty entry: one fortune-cookie line for a crypto trader who has just been liquidated.

## The entry

> A great fortune awaits you at the bottom of the chart — you have already arrived.

## How it works

`main.py` (stdlib only, deterministic) writes the fortune to `/output/entry.txt`:

```sh
python3 main.py
```

Two runs produce byte-identical output. The line is 16 words / 81 characters, within the 20-word and 160-character limits.
